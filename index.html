list
ordered ✓ insertion order
duplicates ✓ allowed
indexed ✓ 0-based, negative
mutable ✓
element types any / mixed
lookup O(n) linear scan
append O(1) amortized
insert O(n) shifts elements
literal [ ] or list()
Basic
for x in lst: print(x)
With index
for i, x in enumerate(lst): print(i, x)
Reversed
for x in reversed(lst): print(x) # or lst[::-1]
Comprehension
squares = [x**2 for x in lst] evens = [x for x in lst if x%2==0]
Zip two lists
for a, b in zip(lst1, lst2): print(a, b)
Append (end)
lst.append(x) # O(1)
Insert at index
lst.insert(0, x) # O(n) lst.insert(i, x) # before i
Extend (merge)
lst.extend(other) # in-place lst += other # same lst + other # new list
Prepend pattern
lst = [x] + lst # new list # prefer collections.deque # for frequent prepends
By index
lst[0] # first lst[-1] # last lst[i] # any
Slice
lst[1:4] # [1,2,3] lst[::2] # every other lst[2:] # from idx 2
Search
lst.index(x) # first idx x in lst # bool O(n) lst.count(x) # occurrences
Min / Max / Sort view
min(lst); max(lst) sorted(lst) # new list
By value
lst.remove(x) # first match # raises ValueError
By index
del lst[i] del lst[1:3] # slice
Pop
lst.pop() # last, O(1) lst.pop(i) # at i, O(n)
Clear / overwrite slice
lst.clear() # empties lst[1:3] = [] # removes range
set
ordered ✗ unordered
duplicates ✗ auto-deduped
indexed ✗ no indexing
mutable ✓ (frozenset: ✗)
element types hashable only
lookup O(1) avg hash-based
add O(1) avg
set ops ∪ ∩ − △
literal { } or set()
Basic (order not guaranteed)
for x in s: print(x)
Sorted iteration
for x in sorted(s): print(x)
Comprehension
squares = {x**2 for x in s}
Set operations
s1 | s2 # union s1 & s2 # intersection s1 - s2 # difference s1 ^ s2 # symmetric diff
Add single element
s.add(x) # O(1) avg
Add many (merge)
s.update(other) # iterable s |= other # same
No insert-at-position
# sets have no positional # insertion — use list or # sortedcontainers.SortedList
Membership test
x in s # O(1) avg x not in s # O(1) avg
No index access
# s[0] → TypeError # peek any element: x = next(iter(s))
Subset / superset
s1 <= s2 # s1 ⊆ s2 s1 < s2 # s1 ⊂ s2 (proper) s1.isdisjoint(s2)
Remove (raises if missing)
s.remove(x) # KeyError if absent
Discard (safe)
s.discard(x) # no error if absent
Pop (arbitrary element)
s.pop() # removes & returns one # KeyError if empty
Clear / difference
s.clear() s -= other # remove all in other
dict
ordered ✓ insertion order (3.7+)
key dupes ✗ keys unique
value dupes ✓ values may repeat
indexed by key only
mutable ✓
key types hashable only
value types any
lookup O(1) avg hash-based
literal {k:v} or dict()
Keys only
for k in d: # default for k in d.keys(): # explicit
Values only
for v in d.values():
Key-value pairs
for k, v in d.items():
Sorted by key
for k in sorted(d): print(k, d[k])
Comprehension
inv = {v: k for k, v in d.items()} sq = {k: k**2 for k in d}
Set / overwrite key
d[k] = v # always O(1)
Set only if missing
d.setdefault(k, v) # returns existing # or sets & returns v
Merge dicts
d.update(other) # in-place d |= other # in-place (3.9+) merged = d | other # new dict (3.9+)
defaultdict pattern
from collections import defaultdict d = defaultdict(list) d[k].append(v) # no KeyError
Direct (raises KeyError)
d[k]
Safe with default
d.get(k) # None if missing d.get(k, default) # custom default
Check key existence
k in d # O(1) k not in d # O(1)
Views (live)
d.keys() # KeysView d.values() # ValuesView d.items() # ItemsView
Delete key (raises if absent)
del d[k]
Pop with default
d.pop(k) # KeyError if absent d.pop(k, default) # safe
Pop last inserted
k, v = d.popitem() # LIFO (3.7+)
Clear
d.clear() # empties dict
bisect
structure sorted list (via bisect)
ordered ✓ always sorted
duplicates ✓ allowed
indexed ✓ standard list
mutable ✓
element types comparable (sortable)
search O(log n)binary search
insert O(n) shifts elements
import import bisect
Same as list — always sorted
for x in lst: # already sorted print(x)
Range iteration (by value)
import bisect lo = bisect.bisect_left(lst, 10) hi = bisect.bisect_right(lst, 20) for x in lst[lo:hi]: print(x) # values in [10, 20]
Comprehension (fine, stays sorted)
evens = [x for x in lst if x%2==0]
Insert maintaining sort order
import bisect bisect.insort(lst, x) # O(n)
insort_left vs insort_right
bisect.insort_left(lst, x) # inserts BEFORE existing equal vals bisect.insort_right(lst, x) # inserts AFTER existing equal vals # insort == insort_right
Manual: find index then insert
i = bisect.bisect_left(lst, x) lst.insert(i, x)
⚠ Never use list.append / insert directly
# would break sort invariant # always use insort()
Binary search (find position)
bisect.bisect_left(lst, x) # index where x would go (left) bisect.bisect_right(lst, x) # index where x would go (right)
Check if value exists
i = bisect.bisect_left(lst, x) found = i < len(lst) and lst[i] == x
Floor / ceiling value
i = bisect.bisect_left(lst, x) floor = lst[i-1] if i > 0 else None ceiling = lst[i] if i < len(lst) else None
By index (normal list access)
lst[0] # smallest lst[-1] # largest
Remove by value (first occurrence)
i = bisect.bisect_left(lst, x) if i < len(lst) and lst[i] == x: lst.pop(i)
Remove all occurrences of x
lo = bisect.bisect_left(lst, x) hi = bisect.bisect_right(lst, x) del lst[lo:hi]
Remove by index (as normal list)
del lst[i] lst.pop() # removes largest lst.pop(0) # removes smallest O(n)
